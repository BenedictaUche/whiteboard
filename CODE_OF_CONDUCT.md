## Our Standard

We want Whiteboard to be a friendly and respectful project where people can learn, contribute, ask questions, and share ideas.

When participating in this project, please:

- Be respectful and considerate
- Assume good intentions
- Give constructive feedback
- Welcome people with different levels of experience
- Keep discussions focused on the project
- Avoid personal attacks, harassment, or discriminatory language

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or personal attacks
- Discrimination or hateful language
- Threats or intimidation
- Sexual harassment
- Deliberately disruptive behavior
- Sharing someone's private information without permission

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the [project maintainer](mailto:benedictaonyebuchi.uche@gmail.com).

Do not create a public issue for sensitive reports.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or take other appropriate action when this Code of Conduct is violated.

We aim to handle reports fairly and respectfully.

## Scope

This Code of Conduct applies to the Whiteboard repository, its issues, pull requests, discussions, and other project spaces maintained by the project.

The repository contains .env.example files with the required variable names but without secret values.

## OpenRouter API Key

Whiteboard uses the OpenRouter API for AI-powered features. The OpenRouter API key must remain server-side and must never be exposed in client-side code.

If you believe an API key has been exposed:

- Revoke or rotate the key immediately.
- Remove it from the affected environment.
- Notify the project maintainer.
- Check whether the key was committed to Git history.

## Responsible Disclosure

Please give the maintainers a reasonable opportunity to investigate and address a vulnerability before publicly disclosing it.

Thank you for helping keep Whiteboard and its contributors safe!
